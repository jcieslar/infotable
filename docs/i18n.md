# InfoTable Internationalization (i18n) Guide

InfoTable supports internationalization in English (en) and Polish (pl) out of the box.

## Configuration

### Setting the Locale

Set the locale in your Rails application:

**config/application.rb**
```ruby
# Set default locale
config.i18n.default_locale = :en

# Available locales
config.i18n.available_locales = [:en, :pl]
```

**Or set per-request in ApplicationController:**
```ruby
class ApplicationController < ActionController::Base
  before_action :set_locale

  private

  def set_locale
    I18n.locale = params[:locale] || I18n.default_locale
  end
end
```

## Customizing Translations

To override or add translations, create locale files in your Rails app:

**config/locales/infotable.en.yml**
```yaml
en:
  infotable:
    table:
      buttons:
        export_csv: "Download CSV"  # Override
```

**config/locales/infotable.pl.yml**
```yaml
pl:
  infotable:
    table:
      buttons:
        export_csv: "Pobierz CSV"  # Override
```

## Adding New Languages

To add a new language (e.g., Spanish):

1. Create **config/locales/infotable.es.yml** in your Rails app
2. Copy the structure from `en.yml` or `pl.yml`
3. Translate all keys
4. Add `:es` to `config.i18n.available_locales`

Example:
```yaml
es:
  infotable:
    table:
      buttons:
        export_csv: "Exportar CSV"
        filters: "Filtros"
      # ... etc
```

## Translation Files Location

InfoTable's default translations are located in:
- `config/locales/en.yml` (English)
- `config/locales/pl.yml` (Polish)

These are automatically loaded by the Rails i18n system.
